01 / 09

GenAI applications fail in ways ordinary monitoring does not show: answers get worse while every health check stays green. This deck separates operational signals, cost signals, quality signals and business signals. Demo: the Eval Harness prints p50, p95, tokens and cost per candidate.

01 / Four layers

Watch four things, not one.

SERVICE

Is it up and fast?

Invocations, latency, throttles, client and server errors.

COST

What does it spend?

Input and output tokens, cache hits, cost per request.

QUALITY

Is it any good?

Eval scores, groundedness, hallucination checks, user feedback.

BUSINESS

Does it help?

Task success, escalation rate, resolution time.

A green dashboard with falling quality is the classic GenAI incident.

03 / 09

Averages hide the slow tail; users complain about p95 and p99. Metric names and dimensions can change as the service evolves, so confirm them in the Bedrock monitoring documentation. Streaming adds time-to-first-token, which you should also track.

03 / Logs

Model invocation logging.

WHAT

Request and response

Prompts, completions, token counts and metadata for each call.

WHERE

CloudWatch Logs or S3

Off by default. Choose the destination, encryption and retention.

CAUTION

It is sensitive data

Logs can hold PII. Mask before the call, restrict access, expire them.

For your own app logs, write structured JSON so metric filters can count failures by type.

05 / Latency

Where does the time go?

PieceLever
Time to first tokenStream the response; choose a smaller model; shorter prompt
RetrievalRight-size k, filter by metadata, tune the index, run in parallel with other work
Model generationCap output tokens; smaller or faster model; latency-optimized inference where supported
Waiting on throttlesRetries cost time: raise quota, spread across Regions, provisioned throughput
Repeated workPrecompute, cache prompt prefixes, cache whole answers where safe
Measure first. Then optimize the biggest slice.

06 / 09

Streaming does not reduce total time but it improves perceived latency. Some models and profiles support an optimized-latency setting: check support with GetFoundationModel. Parallelism applies to independent steps such as several retrievals or tool calls.

06 / Cost

Attribute spend to something.

TAG

Application inference profiles

Create one per assistant or tenant, with cost-allocation tags, then read usage and cost per profile.

RATIO

Cost per 1,000 successes

Tokens times price, divided by successful answers. Failed calls still cost.

ALERT

Budget alarms

Alarm on a token spike so a loop or a bug does not run all weekend.
