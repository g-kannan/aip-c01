Frame the talk: this covers the metrics page of the Amazon Bedrock user guide, which describes judge-based (LLM-as-a-judge) evaluation. An evaluator model reads each response and scores it against a set of metrics. There are eleven built-in metrics and you can also define your own. The page lists the metrics and what each one measures; it does not give scoring scales, so this deck does not either.

03 / 08

The Bedrock page presents the eleven metrics as a flat list. To make them easier to learn, this deck groups them by what question they answer: content metrics ask whether the answer is right and grounded, usefulness and style metrics ask whether it is good to use, and responsible AI metrics ask whether it is safe. The grouping is a teaching aid, not an AWS category.

03 / Content

Is the answer right and grounded?

MetricIdentifierWhat it measures
CorrectnessBuiltin.CorrectnessWhether the response is correct. Considers a reference response if supplied.
CompletenessBuiltin.CompletenessHow well it answers every question in the prompt. Also uses a reference response.
FaithfulnessBuiltin.FaithfulnessWhether it contains information not found in the prompt, so how faithful it is to the available context.
RelevanceBuiltin.RelevanceHow relevant the answer is to the prompt.

Amazon Bedrock · Judge-based evaluation metrics

04 / 08

Correctness and Completeness both consider a reference response when one is provided in the prompt dataset. Faithfulness checks for information that is not found in the prompt, which makes it the metric that catches invented content when you supply context, as in retrieval-augmented prompts. Relevance asks only whether the answer is relevant to the prompt.

04 / Usefulness and style

Is the answer good to use?

MetricIdentifierWhat it measures
HelpfulnessBuiltin.HelpfulnessFollows instructions, is sensible and coherent, and anticipates implicit needs.
Logical coherenceBuiltin.CoherenceLogical gaps, inconsistencies and contradictions in the response.
Following instructionsBuiltin.FollowingInstructionsHow well it respects the exact directions in the prompt.
Professional style and toneBuiltin.ProfessionalStyleAndToneWhether style, formatting and tone suit a professional setting.
Note the identifier: Logical coherence is Builtin.Coherence.

Amazon Bedrock · Judge-based evaluation metrics

05 / 08

Helpfulness is the broadest of the four: the page says it factors in whether the response follows the provided instructions, whether it is sensible and coherent, and whether it anticipates implicit needs and expectations. Logical coherence looks for logical gaps, inconsistencies and contradictions, and its identifier is Builtin.Coherence, which is easy to mistype. Following instructions is narrower than Helpfulness: it looks at whether the exact directions in the prompt are respected.

05 / Responsible AI

Is the answer safe?

MetricIdentifierWhat it measures
HarmfulnessBuiltin.HarmfulnessWhether the response contains harmful content.
StereotypingBuiltin.StereotypingWhether it contains stereotypes of any kind, positive or negative.
RefusalBuiltin.RefusalWhether it directly declines to answer, or rejects the request with reasons.
Read Refusal against the prompt: declining a harmful request is expected, declining a harmless one is not.

Amazon Bedrock · Judge-based evaluation metrics

06 / 08

Stereotyping covers stereotypes of any kind, and the page is explicit that positive stereotypes count as well as negative ones. Refusal determines whether the response directly declines to answer or rejects the request with reasons. The page does not say whether a refusal is good or bad, because that depends on the prompt; the interpretation on the slide is this deck's guidance, not text from the page.
