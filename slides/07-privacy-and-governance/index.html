01 / Isolate

Keep traffic private.

NETWORK

Interface VPC endpoint

Reach bedrock-runtime over PrivateLink from private subnets. No internet gateway or NAT needed.

POLICY

Endpoint policy

Restrict which principals and models the endpoint allows. Combine with aws:SourceVpce in IAM.

PRIVACY

Provider isolation

Bedrock does not use your prompts or answers to train base models, and does not share them with model providers.

Private API variant: execute-api endpoint allow-list in front, Bedrock endpoint behind.

04 / 10

Detection is not perfect, so do not rely on a single detector. Mask before sending to the model if the model does not need the value. Retention rules stop old data piling up.

04 / Logs and retention

Logs are data too.

INVOCATION LOGS

Off by default

Turn on model invocation logging to CloudWatch Logs or S3. They can contain full prompts and answers.

CLOUDTRAIL

Who called what

API activity for audit: caller identity, time, action. Not the prompt text.

TTL

Maximum, not exact

DynamoDB TTL removes expired items typically within a couple of days. Treat it as an upper bound.

This repo's gateway logs request IDs and error codes, not prompt text.

06 / Document

Models, data and lineage.

MODEL CARD

Intended use and risks

SageMaker Model Cards record purpose, evaluation and limitations. A content change makes a new version; approval status is separate.

LINEAGE

Where did it come from

S3 object versions, knowledge-base data source and ingestion job, metadata files.

EVIDENCE

Evaluation reports

Keep the golden dataset, scores and release decision with the version.

Verify the Model Card versioning and approval behaviour in the current API docs before relying on it.

07 / Monitor

Detect misuse, then act automatically.

1 / DETECT

Signals

Guardrail interventions, error rates, token spikes, odd callers.

→

2 / ALARM

CloudWatch

Metric filters on structured logs, then alarms with thresholds.

→

3 / ACT

Remediate

EventBridge to Lambda or Step Functions: tighten a guardrail, roll back a prompt, disable a key.

Metric filters count new log events only; they do not backfill history.
