06 / How to use it

A loop for each task.

Learn

  • Read the slide deck; use the notes
  • Note the exam trap on each slide
  • Check current AWS docs for any specifics

Prove

  • Run the demo and change one setting
  • Explain the result out loud
  • Tick the task in docs/exam-domains.md
Tick a task only when you can explain it and have seen it work.
