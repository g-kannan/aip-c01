# Slide decks

Every deck is a page here, with one section per slide and the speaker notes folded under it, so the site search finds their text. Each page also links to the live deck, a standalone 16:9 presentation: arrow keys, Space, Home and End move between slides, and every slide section has an "Open slide N" link into it.

The pages are generated from the deck HTML when the site is built, so the decks stay the single source.
